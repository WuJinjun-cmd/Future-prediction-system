一、评分体系总览

前途预测系统采用五维等权重评分模型，每个维度独立评分（0-100分），最终取算术平均值作为综合前途评分。

📐 计算公式
总分 = (大学评分 + 专业评分 + 五行命理评分 + 星座评分 + MBTI评分) ÷ 5
总分范围：0 - 100，精确到整数（四舍五入）
维度权重评分区间核心逻辑
🏫 大学20%30 - 100学校层级匹配 + 关键词匹配
💼 专业20%40 - 96专业分类 + 市场需求 + 发展前景
🌟 五行命理20%30 - 100四柱八字 + 五行平衡 + 日主强弱
♈ 星座20%71 - 8812星座性格与职业匹配度
🧠 MBTI20%50 - 9416型人格职场竞争力数据

四、五行命理维度评分

4.1 四柱八字推算

柱推算依据方法
年柱出生年份以公元4年（甲子年）为基准，60甲子循环推算
月柱年干 + 月份五虎遁口诀：甲己之年丙作首……
日柱年月日以1900年1月1日（甲戌日）为基准计算日差
时柱日干 + 出生小时五鼠遁口诀：甲己还加甲……；小时→时辰地支

4.2 五行分析

  • 天干五行：甲乙木、丙丁火、戊己土、庚辛金、壬癸水
  • 地支五行：寅卯木、巳午火、申酉金、亥子水、辰戌丑未土
  • 五行计数：天干每出现1次计1分，地支每出现1次计0.5分
  • 日主（日干五行）：八字的中心，代表命主自身
  • 得令判断：月支五行与日主相同 → 得令（根基深厚）

4.3 五行命理评分公式

日主强度 = min(100, 日主五行计数 × 4)
五行平衡度 = max(0, 100 - 标准差 × 3)
五行命理评分 = 日主强度 × 0.4 + 平衡度 × 0.4 + (得令 ? 20 : 0)
最终取值区间：30 - 100

九、抽签与八卦占卜体系

9.1 千签体系

1000 支签基于《周易》六十四卦演化（64 卦 × 16 变体 ≈ 1024 签）：

  • 吉凶分布：大吉卦（乾、坤、泰、大有等12卦）→ 高分段签文；凶卦（讼、否、剥、困等16卦）→ 低分段；其余为中平
  • 个性化种子：种子 = 哈希(日期 + 用户姓名 + 大学 + 专业 + 出生年月日时 + MBTI)，确保每人每天抽到不同签文
  • 签文内容：签号 + 卦名 + 卦象符号 + 等级 + 签诗 + 白话解读 + 事业/感情/健康三项指引

9.2 八卦占卜 — 六爻起卦

模拟三枚铜钱摇卦过程：

  1. 生成 6 组随机数（0-3），映射为六爻（老阴/少阳/少阴/老阳）
  2. 初爻至三爻 → 下卦（内卦）；四爻至六爻 → 上卦（外卦）
  3. 老阴(0)和老阳(3)为变爻，提示卦象变化趋势
  4. 查表匹配六十四卦，输出卦名、卦象符号、卦辞、白话解读
