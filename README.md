# 🔮 前途预测系统

一个结合理性分析与玄学智慧的前途预测 Web 应用。从**大学、专业、天干地支、星座、MBTI** 五个维度综合评估你的未来发展潜力，给出前途评分和个性化建议。

## ✨ 功能

- **🎓 综合预测** — 填写大学、专业、出生日期和 MBTI，五维等权重计算前途评分
- **📊 可视化结果** — 环形总分、五维雷达图、各维度详情进度条、综合发展建议
- **🔮 每日运势** — 结合星座和天干地支的个性化每日运势（宜忌、幸运元素）+ 每日一签
- **📋 历史记录** — 自动保存预测历史，支持查看详情和删除（localStorage，最多50条）

## 🚀 部署

### GitHub Pages

1. Fork 或克隆本仓库
2. 推送到 GitHub 仓库的 `main` 分支
3. 在仓库 Settings → Pages 中，Source 选择 `main` 分支根目录
4. 保存后即可通过 `https://你的用户名.github.io/仓库名` 访问

### 本地运行

直接在浏览器中打开 `index.html` 即可，无需构建工具或服务器。

## 🛠 技术栈

- 纯 HTML/CSS/JS，无框架依赖
- localStorage 本地存储
- Canvas 绘制雷达图
- SVG 环形进度条
- 响应式设计（移动端适配）
